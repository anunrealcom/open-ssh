小白运维 xiaobaiOP — 绿色便携版 使用说明
============================================

【如何运行】
直接双击 xiaobaiOP.exe 即可，无需安装、无需管理员权限。
所有配置（会话、AI 配置等）保存在程序所在目录或系统用户目录下，
拷走整个文件夹到别的电脑也能用。

【功能一览】
- 新建会话：SSH（Linux）、远程桌面 RDP（Windows）
- 快速连接：填地址/端口/账号一键连
- 文件传输：基于 SSH 的远程文件管理
- 端口转发 / 隧道管理
- 串口调试
- AI 助手：在设置里填入 OpenAI 兼容接口的 apiKey 即可对话

【关于杀毒软件（360 / 腾讯电脑管家）误报】
本程序是个人自用的运维工具，不含任何恶意行为：
它会调用系统自带的 ssh.exe / mstsc.exe 来连接远程主机，
这类“启动外部进程 + 联网”的行为容易被安全软件当成“远程控制木马”启发式误报。

若被杀软拦截，请按以下任一方式处理：
1. 将本程序所在的整个文件夹加入杀软“白名单 / 信任区 / 排除项”。
   （360：设置 → 病毒查杀 → 信任区 → 添加目录；选本文件夹即可）
2. 若仍被杀，可临时关闭杀软实时防护后运行一次，再手动加白。
3. 程序已嵌入版本信息（公司名、产品名、版本号、版权），
   比“无名文件”更不容易被降权，但个人自用未做代码签名，
   首次运行 SmartScreen 可能提示“未知发布者”，点“仍要运行”即可。

如要正式分发给他人，建议购买 Authenticode 代码签名证书后用
signtool 给 exe 签名，可基本杜绝误报。

【重新生成】
源码改动后，用项目根目录的 deploy_release.bat 一键重建 Release 并
自动用 windeployqt 收集依赖到 dist/。要生成 .exe 安装包需先安装
Inno Setup，再右键 xiaobaiOP_setup.iss → Compile。
